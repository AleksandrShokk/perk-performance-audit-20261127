# Токен Wildberries

Ещё → Магазины → нужный магазин → Заменить токен.
Экран показывает статус подключения и срок действия; прежний ключ API не читается.
Замена доступна владельцу/админу и требует существующего сильного подтверждения.

Новая форма: React Hook Form + Zod, схема из OpenAPI. Ключ только в форме/памяти
запроса, не в query key или variables мутации, не в сохраняемом кэше. После успеха
поле очищается. Новая страница не использует вложенные модальные формы.

Бэк: существующий PUT /workspaces/{workspace_id}/stores/{store_id}/credential.
WB проверяет ключ; seller_id должен совпасть с подключённым продавцом. Ошибка
не заменяет старый ключ. В базе ключ зашифрован, в ответе/аудите его нет.
Идентификатор магазина, история и себестоимость сохраняются.

После сохранения разрешённые активные/заблокированные из-за ключа загрузки
перезапрашиваются в фоне, с сохранением курсоров/истории и квот WB. Выключенные
вручную загрузки не включаются. Удалённые из нового токена права отключают только
соответствующий источник. Менять токен в самом WB или автоматически продлевать
его срок PERK не может — пользователь вставляет созданный в WB новый ключ.
