# Доработки по проверке на телефоне — 24 октября 2026

Уточнение главной: в карточке заказов теперь сразу две линии (заказы и выкупы, шт.).
Группировка выбирается выпадающим меню внутри карточки; при открытии — по дням.
Общая надпись «Данные неполные» заменена отдельными пояснениями для графика и финансов.
На рабочем магазине за 90 дней отсутствует только 26 июля в оперативных заказах/выкупах;
финансовый период покрыт полностью. Проверка этой доработки: 5 целевых backend-тестов,
30 frontend-тестов, TypeScript и ESLint.

## Реализация

1. Резервный код копируется нажатием (`expo-clipboard`), показываются галочка и «Скопировано».
   Коды не сохраняются в Query/AsyncStorage; копируется только выбранный код.
2. В «Ещё» пункт привязки телефона скрыт, если номер уже есть.
3. В профиле — «Сменить номер», текущий номер маскирован. Сервер требует сильный step-up
   для смены; после этого подтверждается новый номер. Почта не заменяет сильный фактор.
4. На странице продаж — дни/недели/месяцы. Выбор сохраняется на устройстве, не меняется
   при переключении 7/30/90 дней. Один месяц — одна точка по центру. Недели с понедельника,
   крайние группы обрезаются периодом. Подсказка показывает сумму и неполноту данных.
5. Финансовая история загружается месячными порциями от свежих дат к старым; не одним
   заданием с 2024 года. Периоды предзагружаются после первого ответа, кэш сохраняется.
6. «Обзор» — карточки заказов/выкупов и финансов, плитки тем. График и подробности вынесены
   в `reports/[topic]`. Остатки, воронка и выкупы используют серверные снимки.
   Баланс WB загружается сервером отдельно, без запросов WB при открытии экрана.
7. При нескольких магазинах в переключателе — «Все магазины». Агрегация на сервере,
   только по доступным магазинам текущего рабочего пространства. Балансы разнесены по валютам.
   Списки товаров остаются по магазинам: артикулы разных кабинетов не объединяются.
8. Отчёт за 90 дней сохраняет опубликованные дни при загрузке истории. Если текущая
   загрузка уже затронула день, используется только она; этот день повторно не суммируется.
   При построении новой проекции старая остаётся доступна с неполным покрытием.
9. `Screen` закрывает область под часами/батареей непрозрачной подложкой: текст при
   прокрутке не проступает через строку состояния. Шапка с логотипом остаётся внутри Screen.
10. После пяти ответов 401 на пароль — «Забыли пароль?». Отдельный экран: email → код
    и новый пароль. Повторная отправка обновляет challenge. Успех не создаёт сессию:
    нужно войти заново, включая второй фактор. Ошибки сети не увеличивают счётчик.
11. Блокировка пользователя при входе/OTP — PostgreSQL `FOR NO KEY UPDATE`:
    FK-блокировки фонового импорта (`KEY SHARE`) больше не задерживают вход.
    Финансовые задания ограничены месячными порциями, уменьшая время публикации.

## Границы и проверка

- Backend: 308 тестов на изолированной БД, Ruff clean. Frontend: 29 тестов,
  TypeScript и ESLint clean. Экспорт JavaScript для iOS/Android успешен.
- На подключённом магазине серверная сборка business за 90 дней заняла 0,234 с,
  повторно из кэша — 0,042 с. Это не end-to-end замер на телефоне. Период покрывает
  26 июля — 23 октября, последний месяц присутствует.

- Без готового снимка первый запрос может показывать подготовку. Нулевая задержка при
  первом запуске не обещается; закэшированные экраны открываются без полноэкранной загрузки.
- При отсутствии части магазинов суммы помечены как неполные. `—` не заменяется нулём.
- Суммы заказов из разных кабинетов не складываются: WB statistics не возвращает валюту.
  Количества суммируются, проценты пересчитываются только при полном покрытии.
- «Все магазины» не объединяет разные рабочие пространства PERK.
- Физический iPhone необходим для финальной проверки safe area, нативных вкладок,
  буфера обмена и клавиатуры. Браузер/экспорт не заменяют проверку Expo Go на телефоне.
- Смена номера с настоящей доставкой Telegram/SMS не проверяется локальными fake-провайдерами.

Основные файлы: `features/overview/OverviewScreen.tsx`, `ReportScreen.tsx`, `useBusiness.ts`,
`chartPoints.ts`, `features/auth/screens/ForgotPasswordScreen.tsx`,
`features/auth/components/RecoveryCodes.tsx`.
