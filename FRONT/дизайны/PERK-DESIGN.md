# PERK — дизайн

Спецификация для разработки сайта и мобильного приложения на основе макетов PERK.
Дата: 9 октября 2026 года.

## Базовый набор для начала

Файл `design-tokens.json` содержит 24 значения в четырёх разделах. Это небольшой набор общих значений для мобильного приложения, сайта и расширения. Начать можно только с цветов; размеры и отступы подключаются по мере создания компонентов.

| Раздел | Что в нём |
|---|---|
| colors | Светлая и тёмная палитры с одинаковыми названиями |
| textSize | Пять размеров: дополнительная подпись, основной текст, заголовок раздела, заголовок экрана, главный показатель |
| spacing | Отступы между элементами, карточками и разделами; внутри экрана и карточки |
| cornerRadius | Скругления карточки и кнопки |

Названия цветов: `background.screen` — фон экрана; `background.card` — фон карточки; `text.primary` — основной текст; `text.secondary` — пояснения; `border` — разделители; `accent` — кнопки, ссылки, график и выбранные элементы.

Все числовые значения в JSON — размеры: пиксели на вебе и логические единицы в React Native. Файл хранит обычные данные, которые нужно применить в стилях компонента. Цвета выбираются по теме, остальные три раздела общие.

Пример обращения к значениям:

```ts
tokens.colors.light.background.card
tokens.colors.dark.text.primary
tokens.spacing.cardPadding
tokens.textSize.body
```

Дальнейшие разделы описывают дизайн и возможные детали реализации. Стекло, тени, графики, анимации, служебные цвета и размеры нативной навигации остаются рекомендациями для конкретных компонентов; они не входят в базовый JSON. Дополнительный токен стоит добавлять, когда одна и та же настройка действительно используется в нескольких местах.

## Направление

Светлый минимализм с мягким лавандовым акцентом, крупными финансовыми показателями и прозрачными элементами навигации. Главная страница помогает сразу увидеть выручку, изменение за период и ближайшее полезное действие.

У интерфейса три уровня: спокойный фон → поверхности с данными → элементы управления. Стекло используется в переключателях и навигации. Карточки с цифрами и графиками имеют непрозрачную поверхность для устойчивой читаемости.

Одна общая палитра для сайта, iOS и Android: шесть основных цветов и один фиолетовый акцент. Логотип, кнопки, ссылки, график и выбранные вкладки используют этот акцент. Подложки и стекло получаются из той же палитры через прозрачность. Для реализации размеры приведены к общей шкале, а дополнительные подписи — к размеру от 12.

## Цвета

Цвет выбирается по назначению. В коде достаточно одного объекта темы с шестью цветовыми ролями. Тёмная тема меняет значения этих же ролей.

| Назначение / токен | Светлая тема | Тёмная тема |
|---|---|---|
| Фон экрана / background.screen | #F7F7FB | #16161E |
| Карточки и панели / background.card | #FFFFFF | #22222E |
| Основной текст / text.primary | #242436 | #F4F4F8 |
| Дополнительные подписи / text.secondary | #6B6B80 | #A8A8BC |
| Декоративные разделители / border | #E5E5F0 | #363647 |
| Единый фиолетовый акцент / accent | #625DD5 | #A5A0FF |

Правила применения:

- Обычная карточка — background.card, основной текст и цифры — text.primary, пояснения — text.secondary.
- Главная кнопка — accent; её текст — background.card в светлой теме и background.screen в тёмной.
- Лавандовая подложка — accent с непрозрачностью 8% поверх background.card в светлой теме и 12% в тёмной. Так выделяются главная карточка и активная вкладка.
- Вложенная спокойная поверхность — background.screen. Разделители — border. Для видимой границы поля ввода используем text.secondary, для фокуса — accent.
- Стекло — background.card с непрозрачностью 70% в светлой теме и 85% в тёмной, плюс размытие. Граница — border.
- Наведение и нажатие — лёгкое изменение прозрачности или масштаба. Отдельные цвета состояний не добавляем.

Вне основной палитры есть два служебных цвета: success — #25775D / #76D1B1; error — #B23A4B / #FF9CA8. Они используются только для подтверждённого статуса, роста, ошибки или отрицательной динамики. Предупреждение использует accent, значок и понятный текст. Значение и подпись сохраняют смысл без различения цветов.

Для обычного небольшого текста задаём целевой контраст не ниже 4.5:1 на его фактической поверхности. Accent на белом — 5.19:1. Прозрачные поверхности проверяются вместе с фоном под ними.

## Фон и глубина

Основной фон — ровный background.screen. Внутри карточек показателей используется background.card; главная карточка может иметь лёгкую подложку из accent.

Сетка с точками, рамка телефона, отверстие камеры и системная строка в макетах относятся к презентации устройства; интерфейс приложения располагается внутри системных безопасных отступов.

Большинство карточек отделяются от фона цветом поверхности и расстоянием. Мягкая тень нужна для стеклянных элементов, всплывающих меню и панелей поверх экрана.

## Шрифты

| Платформа | Шрифт для реализации |
|---|---|
| Сайт | Inter; fallback: system-ui, sans-serif |
| iOS | Системный шрифт iOS, SF Pro через system font |
| Android | Системный Roboto |
| Логотип PERK | Единый готовый знак и надпись для всех платформ |

В первом мобильном веб-макете задан Inter с системным fallback. В Android-макете используется Roboto. Для самого iOS-приложения выбираем системную типографику.

| Роль | Сайт, px | Мобильное приложение, логический размер | Начертание |
|---|---:|---:|---:|
| Название страницы | 28–32 | 28–30 | 600 |
| Главный показатель | 32–40 | 34–38; 32 на узком экране | 500–600 |
| Заголовок раздела | 16–18 | 16–18 | 600 |
| Значение второго уровня | 20–24 | 18–22 | 500–600 |
| Основной текст | 14–16 | 16 | 400 |
| Название показателя или товара | 13–14 | 14 | 400–500 |
| Дополнительная подпись | 12–13 | 12–13 | 400 |
| Подпись нативной вкладки | По компоненту | По системе; ориентир 12 | По системе |

Начертание 700 используем преимущественно в логотипе. Основной межстрочный интервал — 1.4–1.5; для крупных чисел — 1.1–1.2. Межбуквенный интервал обычного текста — 0; у больших чисел можно использовать -0.5…-1 px.

Для сумм и таблиц — цифры одинаковой ширины, выравнивание чисел по правому краю. Валюта имеет меньший размер, но остаётся читаемой. Пример: «1 284 600 ₽».

Размеры в React Native — логические единицы. Поддерживаем системное увеличение текста и перенос подписи; при увеличении шрифта карточка может вырасти по высоте.

## Стекло

Применение: переключатель периода, отдельные круглые действия, выбранный пункт боковой навигации и плавающие элементы там, где их поддерживает платформа.

| Параметр для веба | Светлая тема | Тёмная тема |
|---|---|---|
| Подложка | background.card, непрозрачность 70% | background.card, непрозрачность 85% |
| Граница, 1 px | border | border |
| Размытие фона | 22–24 px | 22–24 px |
| Насыщенность слоя | 150–170% | 150–170% |
| Мягкая внешняя тень | text.primary, непрозрачность 9%; сдвиг 6, размытие 24 px | background.screen, непрозрачность 65%; сдвиг 6, размытие 24 px |

Допустима тонкая внутренняя подсветка сверху цветом background.card через прозрачность. Для всех собственных стеклянных элементов используем одну настройку на тему.

CSS blur в пикселях служит ориентиром для веба. У Expo BlurView параметр intensity имеет отдельную шкалу 1–100; визуальную силу подбираем на устройстве. Для iOS 26+ Expo предоставляет GlassView с настоящим системным эффектом. На неподдерживаемых платформах GlassView возвращает обычную View, поэтому запасная поверхность должна оставаться читаемой.

Источники: [Expo GlassEffect](https://docs.expo.dev/versions/latest/sdk/glass-effect/), [Expo BlurView](https://docs.expo.dev/versions/latest/sdk/blur-view/).

## Навигация

Мобильные разделы: Обзор, Товары, Финансы, Ещё. Основной контент прокручивается, нижняя навигация сохраняется у нижнего края с учётом системной области.

Android использует Expo Native Tabs и панель Material 3. В выбранном варианте фиксируем цвета PERK:

| Цвет нативной панели Android | Светлая тема | Тёмная тема |
|---|---|---|
| Фон | background.card | background.card |
| Капсула активной иконки | accent, 8% поверх background.card | accent, 12% поверх background.card |
| Активная иконка и подпись | accent | accent |
| Неактивная иконка и подпись | text.secondary | text.secondary |

Капсула 64 × 32 и иконка 24 в макете — визуальные ориентиры. Итоговую геометрию и системные анимации обеспечивает Native Tabs. В Expo доступны настройки backgroundColor, indicatorColor, iconColor и labelStyle. Передаём в них значения общей темы PERK.

iOS использует тот же набор вкладок и системную панель; на поддерживаемой системе применяется Liquid Glass. На сайте основные разделы расположены слева; профиль и настройки — в нижней части боковой панели.

Источники: [Expo Native Tabs](https://docs.expo.dev/router/advanced/native-tabs/), [API Native Tabs](https://docs.expo.dev/versions/latest/sdk/router/native-tabs/), [Material 3 и динамические цвета в Expo](https://expo.dev/blog/expo-router-v55-more-native-navigation-more-powerful-web).

## Структура главной

На телефоне порядок такой: магазин и статус обновления → название страницы → период → большая карточка выручки с графиком → продажи и возвраты → статус прибыли с действием → лидеры продаж.

На сайте: боковая навигация → название и период → три показателя в ряд → график и ближайшее действие → таблица лидеров. На узком экране блоки переходят в один столбец. Дополнительные данные товара доступны в деталях, если все колонки таблицы одновременно не помещаются.

Для главной версии приложения базовые показатели — выручка, продажи и возвраты. Средний чек, показанный в демонстрационном макете, добавляется после согласования определения и контракта API. Демонстрационные значения не становятся данными подключённого магазина.

При неполном расчёте прибыль отображается как «—», рядом — понятная причина и действие «Добавить себестоимость». Заполненная себестоимость сама по себе не снимает другие причины неполноты, например недостающие расходы отчётов.

## Компоненты

Главная кнопка: accent, текст background.card в светлой теме и background.screen в тёмной; высота 48, радиус 14, начертание 500. Во время выполнения — индикатор и сохранение ширины кнопки. Дополнительное действие — спокойная поверхность или текстовая ссылка accent.

Переключатель периода: единая стеклянная капсула, три равных или подходящих по тексту сегмента. Выбранный сегмент имеет background.card, лёгкую тень и text.primary. Метки: 7 дней, 30 дней, 90 дней.

Карточка показателя: подпись → крупное значение → изменение или короткая причина. У основного показателя допускается лавандовая поверхность. Изменение показывается стрелкой, знаком и процентом.

Поля: постоянная подпись над полем, размер текста 16 в приложении, высота 48–52. Ошибка привязана к своему полю и объясняет исправление. Placeholder служит примером заполнения.

Строка товара: миниатюра или спокойный значок, название, дополнительная подпись, сумма справа. Ориентировочная высота 56–64; длинное название может занять две строки. В рабочем приложении используются фотографии каталога, когда они доступны.

ABC: компактная плашка с буквами A/B/C. Буква и выбранная метрика всегда видимы. Цвет помогает считывать плашку, но классификация остаётся понятной по тексту.

## График

Одна основная линия цвета accent; толщина 2–2.5. Заливка под линией — тот же цвет с непрозрачностью 6%. Сетка — тонкая border, подписи осей — text.secondary, размер 12.

На телефоне обычно три подписи дат; на сайте четыре–шесть. Есть единицы измерения, выбранный период и подсказка даты/значения по нажатию или наведению. Валюты отображаются отдельно. Название даты соответствует источнику данных: для финансового графика — отражение в отчёте WB.

## Состояния и движение

| Состояние | Отображение |
|---|---|
| Загрузка | Спокойные placeholders на месте показателей и графика |
| Сводка готовится | «Готовим данные»; без выдуманного значения |
| Магазин ещё не подключён | Короткое пояснение и «Подключить Wildberries» |
| Период пустой | «За этот период данных пока нет» и выбор другого периода |
| Прибыль неполная | «—», причина и следующий шаг |
| Ошибка обновления | Время последних данных, короткое сообщение и повтор |
| Выбранное действие | Контрастная заливка/капсула и текстовая метка |
| Фокус клавиатуры | Видимое кольцо accent, около 2 px |

Небольшие переключения — 180–220 мс; собственная всплывающая панель — 240–300 мс. Нативные вкладки сохраняют системное поведение. Системные настройки уменьшения движения и прозрачности учитываются: в таком режиме используется спокойная читаемая поверхность.

## Форматирование

Интерфейс — на русском. Деньги: «1 284 600 ₽», дополнительные расходы с копейками при необходимости. Количество: «342 шт.». Процент: «+12,8%». Дата: «24–30 сентября»; время обновления: «Обновлено в 10:42».

Неизвестная сумма отображается «—», известный ноль — «0 ₽». Даты, валюты, источник графика и полнота прибыли сохраняются в явных подписях.
