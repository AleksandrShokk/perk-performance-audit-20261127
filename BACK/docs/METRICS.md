# Правила метрик

Расчёты количества продаж/возвратов, динамики по дням и ABC по количеству реализованы;
правила источников и дат описаны в [sales-history.md](sales-history.md). Финансовые строки
расширены, но прибыль и себестоимость пока не рассчитываются: см. [FINANCE.md](FINANCE.md).
Перед каждым новым модулем правила и примеры сверяем с конкретным отчётом площадки.

| Показатель | Основное правило |
|---|---|
| Заказы | Дата заказа, отдельно количество единиц и число заказов |
| Продажи/выкупы | Дата события продажи по источнику; не смешивать с датой заказа |
| Возвраты | Отдельные события и суммы, связь с исходной продажей по возможности |
| Выручка | Продажи минус возвраты по явно выбранной базе цены |
| Процент выкупа | Когорты заказов, с указанием периода наблюдения и незавершённых заказов |
| Выплата | Фактическое движение денег; не равно прибыли |
| К перечислению по отчёту WB | `for_pay` из отчёта; не подтверждает банковскую выплату и не равно прибыли |
| Прибыль | Выручка минус себестоимость и согласованный набор расходов, плюс компенсации |
| Маржинальность | Прибыль / выручка × 100; при нулевой выручке показатель недоступен |
| ROI | Прибыль / явно названная база затрат × 100; при нулевой базе недоступен |
| ABC | Сортировка по выбранному вкладу, доля, накопленная доля, группа A/B/C |
| ДРР | Расход рекламы / выбранный вид выручки × 100; база всегда указана в ответе |

## Принципы

- Decimal / NUMERIC для денег; валюта обязательна. Проценты округляем при представлении.
- Расходы, неизвестная себестоимость и пропущенные периоды не превращаются в нули.
- Полнота отчёта и дата последнего обновления входят в ответ API.
- Финансовая дата, дата заказа, дата продажи и дата возврата — разные поля.
- Себестоимость зависит от даты/партии; новые цены не меняют автоматически закрытые периоды.
- Общие расходы распределяются по явно указанному правилу, остаток нераспределённых виден.
- Для ABC по прибыли убытки выделяются отдельно; перед кодом зафиксировать обработку границ,
  одинаковых значений и товара, который пересекает порог 80/95 процентов.
- Нулевые продажи при отсутствии товара не равны нулевому спросу.
- Налоги настраиваются под магазин; конкретный режим и правила требуют отдельного согласования.
