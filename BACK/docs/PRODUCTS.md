# Каталог и себестоимость — 02.11.2026

`GET /api/v1/workspaces/{workspace_id}/products` читает опубликованный каталог,
остатки и цены. Запрос не вызывает WB. Без `store_id` возвращаются все доступные
активные магазины: одинаковые артикулы разных магазинов остаются отдельными карточками.

Параметры: `q`, `in_stock`, `missing_cost`, `limit` (до 100), `offset`.
Поиск работает по названию, артикулу продавца/WB, бренду, цвету и штрихкодам.
Фильтры применяются до пагинации, итоги относятся ко всем найденным карточкам.
Размеры связаны с остатками по `chrt_id`; альтернативные штрихкоды не умножают запас.
Нет успешной загрузки остатков — `null`, успешная загрузка без строк — известный ноль.
Для старого снимка сохраняются дата и признак `stock_stale`.

Цвет сохраняется из характеристики «Цвет» при очередном импорте каталога.
Старые строки без этого поля остаются без цвета, значение не придумывается.
Отдельных запросов к WB и изменений цен на площадке нет.

Доступ: `inventory.read` открывает остатки, `profit.read` — себестоимость.
Достаточно любого из двух прав для чтения каталога. Суммы/остатки другого раздела
скрываются на сервере. Фильтрация по недоступной себестоимости/остаткам запрещена.
Проверяются RLS, пространство и список магазинов сотрудника.

`POST /api/v1/workspaces/{workspace_id}/stores/{store_id}/costs` добавляет `CostInput`
с `nm_id`, `barcode`, `amount`, `currency`, `effective_from`. Требуется `costs.write`.
Пустой штрихкод — общая цена артикула; конкретный штрихкод имеет приоритет.
Известный ноль допустим, деньги обрабатываются Decimal и шифруются штатным vault.
Артикул и штрихкод должны принадлежать каталогу магазина.
Повтор той же цены на ту же дату идемпотентен. Другую цену на существующую дату
сервер отклоняет 409: история append-only. Новая дата не переписывает прошлые периоды.
Изменение фиксируется в аудите. Формы обновляют каталог и финансовый кэш.

`GET .../costs?nm_id=...` возвращает историю выбранного артикула, сначала новые даты.
Продолжают работать общий список, XLSX-шаблон, предпросмотр и применение импорта.
Новые таблицы и миграции не потребовались. OpenAPI и клиент TypeScript обновлены.
