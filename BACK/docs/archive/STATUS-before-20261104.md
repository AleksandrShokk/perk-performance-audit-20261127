# Статус PERK Backend

Дата: 24 октября 2026. Локальная бета; основной API доступен для разработки
фронтенда. Публичный production ещё не готов. Локальная консоль — инструмент разработки.

Мобильная проверка: исправлены блокировка входа во время импорта и исчезновение
опубликованных дней в preview. История финансов — месячными порциями; добавлены баланс WB
и сводный `/business` по доступным магазинам. Миграция `0016_wb_balance`, 308 тестов проходят.
Подробности: [REVIEW_FIXES_2026_10_24.md](REVIEW_FIXES_2026_10_24.md).

## Реализовано

| Блок | Возможности | Ограничения |
|---|---|---|
| Основа | FastAPI/OpenAPI, PostgreSQL, Redis/Celery (отдельные очереди синхронизации и тяжёлых расчётов), Docker, миграции до 0015, gzip, порционная очистка устаревших данных, ограничение параллельных Argon2 | Проверено локально; публичного размещения нет |
| Заказы WB | Загрузка заказов (90 дней, обновление 30 мин), отчёт заказов/отмен/выкупов по дням и товарам, блок на дашборде | % выкупа — отношение за период, не по каждому заказу |
| Воронка WB | Переходы в карточку → корзины → заказы → выкупы, дневные/SKU агрегаты, взвешенные конверсии, снимки | До 360 дней загрузки; выкупы по дню заказа; начальная загрузка ограничена квотами WB; реальные ответы ещё не сверялись |
| Возвраты продавцу WB | Возвраты по типам/статусам/SKU, товары в ПВЗ со сроком хранения и предупреждением об истечении | История 180 дней; заявки покупателей ждут подтверждения права токена |
| Выкупы за любой период | Отчёт выкупов по дате продажи с 29.01.2024: свежие дни из отчёта о продажах, старые — из финотчётов; сезонность по дате продажи | Суммы двух источников не складываются (разная основа цены); день из финотчёта известен через 30 дней |
| Команда | Приглашения на подтверждённый email, owner/viewer, смена роли, исключение и выход, защита создателя | Передача владения не реализована; приглашение owner требует сильного фактора |
| Диагностика | ErrorResponse с сохранённым detail, X-Request-ID, корреляция HTTP → Celery, безопасное место ошибки в логах | Не заменяет мониторинг и измерение p95 |
| Аудит 21.10.2026 | Исправлены A01–A11: версия налоговых правок, единичный расчёт снимка, реальные даты остатков, права ограниченной сессии, транзакционный actor, неизвестные дни, ETag через CORS, единая проверка периода, быстрый поиск цен, очереди, лимит Argon2 | Не сделано: раздельные агрегаты сводки/дней/товаров, инкрементальная финансовая проекция, метрики p50/p95, нагрузочный тест |
| Быстрая загрузка | Фоновые зашифрованные снимки отчётов, отдача прежнего снимка с `stale` во время пересчёта, ETag/304, главный экран одним запросом | Нестандартный период считается один раз при первом запросе |
| Деньги | Аудит потерь, юнит-экономика, симулятор цены и точка безубыточности, налоги по датам, чистая прибыль, план/факт | Налоги — оценка: без страховых взносов и годовых правил |
| Остатки | Ежедневные снимки, прогноз окончания, упущенная выручка, план поставок по складам спроса и размерам, сезонность | Спрос по неотменённым заказам, если они покрывают окно, иначе по выкупам |
| Уведомления | Лента, утренняя сводка, тревоги (остатки, падение продаж, токен, ошибки загрузки), Telegram-бот, Expo push | Реальная отправка требует токена бота и сборки приложения с push |
| Авторизация | Открытая регистрация с кодом на почту; вход паролем + код в Telegram/SMS (без телефона — на почту); приложение-аутентификатор по желанию; recovery-коды; подтверждение опасных действий; сброс пароля; ротация refresh | Реальная отправка: SMTP и Telegram Gateway; SMS пока только тестовый провайдер (код в логе) |
| Доступ | FORCE RLS на данных и метаданных кабинетов, credential, membership, журнале; ограниченная роль БД | sync_runs остаётся outbox без RLS; API/worker пока используют одну runtime-роль. См. TEAM.md |
| Подключение WB | Проверка read-only прав и продавца, шифрование ключа, статус | Остатки требуют подходящего типа/прав токена |
| Загрузка WB | Каталог, продажи/возвраты, FBW-остатки, финансы, продолжение и обновления | История и скорость зависят от WB и полноты загрузки |
| Продажи | Дни, сводка, ABC по количеству, история из финансовых отчётов, кэш | Источники не складываются; учитывается покрытие |
| Себестоимость | XLSX с выбором валюты, предпросмотр/применение, цены по датам/вариантам | Нужен каталог; автоматической конвертации валют нет |
| Внешние расходы | Сумма, дата, валюта, комментарий, идемпотентность и логическое удаление | Учитываются на уровне магазина, без распределения по SKU |
| Предварительные финансы | Сводка/дни/товары, себестоимость, расходы, возвраты, ABC по выручке/вкладу | До налогов; неизвестные операции и неполные строки блокируют точную прибыль |
| Быстрое чтение | Фоновые дневные факты, зашифрованный кэш по версии данных | Начальная подготовка отличается от повторного чтения |
| Частичный финансовый график | Снимок активного импорта, исправления показанных дней, is_partial, откат к успешному итогу при ошибке | Частичный снимок включает текущий импорт; неподтверждённая прибыль остаётся null |

## Проверено

- 300 тестов прошли в отдельном контейнерном стеке с искусственными данными (23.10.2026).
- Новые сценарии проверяют финансовый preview, порции, исправления/повторы, завершение,
  ошибки, повторный импорт, время снимка, неизвестные дни и конкурентное обновление.
- Проверены RLS/MFA/роли, чужие магазины, идемпотентность, откат публикации, варианты цен,
  возвраты по исходной продаже, разделение валют и обновление кэша.
- Alembic check: расхождений нет. Последняя проверка Bandit: срабатываний нет.
- Исторический замер предыдущего этапа: подготовка сохранённой истории — около 33 секунд;
  локальное чтение месяца — 337 мс, повторное — 24 мс. После новых изменений производительность
  заново не измерялась. Это наблюдение на одном стенде,
  не гарантия для любого магазина или HTTP-запроса с телефона.
- Полная независимая сверка денег с WB и проверка настоящего фронта ещё не завершены.
  История проверок: [VALIDATION.md](VALIDATION.md).
